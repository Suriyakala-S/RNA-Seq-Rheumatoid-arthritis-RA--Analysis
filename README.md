Differential gene expression analysis of Rheumatoid Arthritis using GEO dataset


# 🧬 RNA-Seq Analysis: Rheumatoid Arthritis vs Control
## 📌 Overview
This project performs differential gene expression analysis between Rheumatoid Arthritis (RA) and healthy control samples.
---
## 📊 Dataset
* Source: GEO (GSE1919)
* Samples: RA vs Control
---
## ⚙️ Methods
* Data retrieval using GEOquery
* Differential expression using limma
* Visualization using PCA, heatmap, and volcano plot
---
## 📈 Results
* PCA shows clear separation between RA and control samples
* Heatmap shows distinct gene expression patterns
* Significant differentially expressed genes identified
---
## 🛠 Tools Used
* R
* GEOquery
* limma
* ggplot2
